Hive

Hive is a personal, self-hosted assistant. It runs on the computers its owner already has at home, and it answers only to that owner.

Hive can read its owner's Google Calendar, with the owner's permission, so it can remind them of what is coming up. It runs entirely on the owner's own machines: no service run by Hive's developer sees the owner's data.
