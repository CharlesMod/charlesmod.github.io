Hive privacy policy

Last updated: November 9, 2026

Hive is software that its owner installs and runs on their own computers. This policy covers what Hive does with Google user data when its owner connects a Google account.

What Hive accesses

When the owner chooses "Connect Google", Hive asks Google for read-only access to their Google Calendar (https://www.googleapis.com/auth/calendar.readonly). Hive reads calendar events so it can tell its owner what is coming up. It cannot create, change or delete events.

Where the data goes

  • Calendar data and the access token Google issues stay on the owner's own machines. The token is stored sealed and is never written to logs.
  • Hive's developer runs no server that receives Google user data. Nothing is sent to the developer or to any third party.
  • Google user data is not sold, not used for advertising, and not used to train AI models.

Hive's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can disconnect Hive at any time at myaccount.google.com/permissions. Disconnecting stops all further access. Calendar data Hive has already read stays only on the owner's machines, where the owner can delete it.
